One sentence, at most 200 characters, about the best meal I ever had — entered in [The Best Meal You Ever Had](https://make.fun/bounty/u-pangg7-the-best-meal-you-ever-had-a3ac0f85) on make.fun.

## The entry

> A nameless cart in Makassar sold me soto ayam for 5,000 rupiah, and I ate it standing in midnight rain, the broth fogging my glasses, happier than at any white-tablecloth dinner since.

## How it works

`main.py` writes that single sentence to the output file the sealed scorer reads (`/output/entry.txt`, or wherever `ENTRY_OUT` / `ENTRY_OUT_DIR` points). No network, no dependencies, no secrets — just the sentence.

```sh
python3 main.py
```
